# KYNDER website — what we still need from you

This is a plain-language checklist of everything the website is waiting on before
it can go live. Nothing here is a bug: the site was deliberately built to show a
clearly-marked placeholder wherever your final wording, photography, pricing or an
account is not yet decided — rather than us inventing something on your behalf.

Wherever you see text in square brackets on the live preview — for example
`[PENDING: session price]` — that is a placeholder waiting for the real content
below. It will never be replaced with guessed content; only you can supply it.

How to read this: each item says **what we need** and **where it shows up**. You
can send answers in any format (email, a document, a call) — your developer will
put them in. Items marked **Blocks launch** must be resolved before the site can
be published; the rest can follow shortly after.
